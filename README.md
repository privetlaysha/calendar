# Календарь публикаций — Instagram

Контент-план публикаций Instagram для брендов PESHKOV SHOES и SHOPOMANIIA.
Данные подтягиваются из Metricool.

## Состав

- `index.html` — сам сайт (вход по паролю, календарь по месяцам, детали по дню)
- `data.json` — данные о запланированных постах (обновляются синхронизацией)

## Обновление данных

Данные обновляются кнопкой «Обновить данные» на дашборде Kimi Work —
скрипт `sync.py` тянет свежие посты из Metricool и пушит новый `data.json` в этот репозиторий.
